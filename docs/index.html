VDOWN

NÖDLANDNING PÅ VEYRA

Ett 3D-överlevnadsspel i webbläsaren (Three.js + Vite). Ladda ner källkoden som zip, eller klona repot.

Ladda ner zip Öppna på GitHub 
git clone https://github.com/Lightdoor058/vdown.git
cd vdown
npm install
npm run dev

Kör sedan adressen Vite visar, oftast http://localhost:5173. Modellerna ligger i public/models/.
